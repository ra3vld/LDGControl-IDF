    Install firmware

    Use the prepared build for your board.

    1. Connect the board using a USB data cable.
    2. Close serial monitors and other applications using the device.
    3. Check the profile and select the USB port.

    Complete step 4 before installing, or uncheck this option and configure later.

    What happens to saved settings?

    If problems persist after installation, repeat with Erase device. Full erase removes settings; enter them again afterwards. Without erase, NVS is preserved.

    If connection fails: hold BOOT, press and release EN/RESET, then release BOOT. Desktop Chrome or Edge with Web Serial is required.

    04

    Set up your device

    Apply settings after installation or connect an already flashed board.

    Wi-Fi and your own broker require no registration. You can add the device to rotator.r3v.ru later.

    Port 8883 uses TLS with certificate and hostname verification. Other ports use plain MQTT.

    After connecting USB, open the account sign-in and consent link. Wi-Fi and private broker credentials go only to the board over USB.

    Cannot reach rotator.r3v.ru?

    If the browser reports ERR_BLOCKED_BY_CLIENT, allow requests to rotator.r3v.ru in your ad blocker for ra3vld.github.io. Retry in this tab; reinstalling is unnecessary.

    05

    Connections and next steps

    Open the wiring for your selected board before attaching LDG.

    Open peripheral wiring ↗

    1. Open the device page on the same network. Check Wi-Fi and MQTT status in Settings.
    2. Choose local LDG or the remote-panel role, and configure only the integrations you need.
    3. Check antenna ports, names and automatic switching before use.

    USB setup and troubleshooting ↗

    No network connection?

    Join the LDGControl-IDF Wi-Fi access point, password ldgcontrol. Then open the access-point page. Your computer must be connected to that Wi-Fi network.

    Open access-point page ↗

    Default web login: admin / change_me_please. Change it in the device settings.

    Correct Wi-Fi settings in step 4 and apply again, or use Check connection over USB to read status without changing settings.
